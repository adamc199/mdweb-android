# MD Web

A reader for the web of Markdown pages.

Type or paste the address of a Markdown page in the box at the top. Links to Markdown pages open here; links to HTML pages open in your phone's browser.

### Places to start

* [dave.writersweb.org](https://dave.writersweb.org/), Dave Winer's Markdown site
* [Scripting News](https://dave.writersweb.org/scripting/), as Markdown, back to 2017
* [inessential](https://brent.writersweb.org/), Brent Simmons' blog
* [Bloatware](https://demo.bloatware.org/), a small made-up company site served from GitHub
* [How a Markdown web page works](https://dave.writersweb.org/docs.md)

### Using it

* **Tabs** are across the top. Tap **+** for a new one, long-press a tab to close it.
* **Long-press a link** to open it in a new tab, copy it or open it in the browser.
* **‹ ›** at the top right step to the page before and after, when the site has a table of contents.
* **A** picks how pages look: Reader, Newsprint, Classic, Mono or Book.
* **⋮** has bookmarks (with Edit…), history, find in page, view source and your own stylesheet.
* **📅** (top right) and **Calendar…** in **⋮** show a blog's posts by month and day, on sites that have a dated table of contents.
* A link to a site's HTML version opens its Markdown copy here, when the site has one.
* One word in the address box (no dot or slash) **searches the site** you are on, if it has a search.
* Pages on sites that offer it **update by themselves** when the writer changes them.
* An orange **RSS** button at the top right means the page or its site has a feed: tap it to add the feed to your **📰 River**, the newest items from all your feeds in one list, each with **Copy link** and **Unsubscribe**.

Built on the open Markdown-web format described in the BonBon charter, so the same pages work in BonBon and here.
